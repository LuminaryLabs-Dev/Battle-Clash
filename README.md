# Battle Clash

Planning repository for an original, browser-based village battle game built
with NexusEngine and Three.js.

## Status

Planning and architecture only. No gameplay implementation exists yet.

## Direction

- Bird's-eye orthographic battlefield.
- Colored cubes for all greybox actors and structures.
- Entity-component-system gameplay driven by plain data.
- Layered game domains composed from NexusEngine Core domains and atomic kits.
- Three.js acts only as a renderer/host adapter.

See [MASTER_PLAN.md](MASTER_PLAN.md) for the implementation plan.
